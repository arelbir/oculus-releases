# Oculus — sürümler

Oculus PDF düzenleyicinin Windows kurulum dosyaları ve otomatik güncelleme bildirimleri.

**İndirme:** [En son sürüm](https://github.com/arelbir/oculus-releases/releases/latest) → `Oculus_<sürüm>_x64-setup.exe`

- Yönetici yetkisi gerekmez; kullanıcı hesabına kurulur.
- Kurulum dosyası imzasız olduğu için Windows ilk açılışta "Bilinmeyen yayıncı" uyarısı verebilir:
  **Ek bilgi → Yine de çalıştır**.
- Kurulduktan sonra yeni sürümler uygulama içinden otomatik olarak gelir.
  Güncellemeler kriptografik olarak imzalıdır; uygulama yalnızca imzalı sürümleri kurar.

Bu depo yalnızca kurulum dosyalarını içerir.
